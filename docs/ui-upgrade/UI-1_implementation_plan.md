# UI-1 功能差异与分模块实施计划（已确认）

基线：`0136ee9e03727314102cc041d52dd488cca50def`。完整冻结内容见 [UI-0](UI-0_audit.md)、[逐控件表](UI-0_controls.md)、[指纹清单](UI-0_source_inventory.json)。本方案已于 2026-10-16 获用户确认并授权开发、提交和推送。下文保留原方案；实际执行及验收边界见 [交付记录](UI-2_delivery.md)。

## 1. 决策与视觉方向

采用原型的深蓝侧栏、浅灰蓝页面、白色卡片、蓝色主操作、细边框与层级清晰的标题/表格/状态标签。严格沿用现有 Vue 组件、文本、输入、操作和数据，原型 HTML/JS/mock/hash 路由不进入生产代码。

建议设计变量（由原型提取；可按可读性微调，不改业务含义）：

| Token | 目标 |
| --- | --- |
| 页面 / 表面 / 分隔 | `#f3f6fb` / `#ffffff` / `#e7ecf3` |
| 主文字 / 次级文字 | `#16233b` / `#33435a` |
| 辅助文字 | `#7b899d` 仅用于满足对比度的场合；正文/重要提示使用更深文字 |
| 侧栏 | `#121e33`，桌面宽度约 238px，可按现有布局安全适配 |
| 主色 / 浅主色 | `#3e65ef` / `#edf2ff` |
| 正 / 负 / 警告 | `#219875` / `#d7505e` / `#b98025`，保留原金融涨红跌绿语义，不机械套用成功/失败颜色 |
| 卡片 | 14px 圆角、细边框，轻阴影 `0 3px 14px rgba(39,60,95,.025)` |
| 间距 / 字体 | 统一 4/8/12/16/20/24 节奏，系统本地中文字体与等宽数字，不引入在线字体/依赖 |

只重整视觉层级，不重命名标题、英文字段、状态码与按钮，不新增产品承诺或投资暗示。状态仍需原文字区分，不能只靠颜色。

## 3. 修改范围和停工条件

首批开放：`frontend/src/style.css` 的视觉变量与规则、现有 Vue `<style>`、必要静态 class，以及经单独审查的无行为容器。主批次不新增依赖，不移动业务脚本，不重构组件，不修改服务、类型、工具、构建/部署配置与后端。

保护项：所有 `@click/@submit/@input/@change`、原生 form/type、v-model 修饰符、v-if/v-show/v-for/key、禁用/required/pattern/min/max、title/aria 语义、props/emits、watch/computed、请求/轮询/取消、数值格式及完整文案。首批要求所有 Vue 脚本指纹保持一致。

图表先通过容器/标题/布局统一外观。若 ECharts 内部颜色、字体等必须改脚本，先单独提交仅外观属性的白名单差异，复核 series/data/formatter/tooltip/坐标含义/精度/标记/缩放全不变并获得确认，再实施；不将图表脚本修改混入 CSS 批次。

出现下列任一项即阻断当前批次：

- 功能入口或文案减少/新增/改名，表列/字段/筛选变化，独立操作被并入菜单。
- 条件或事件/绑定/脚本发生非授权差异；通过 CSS 隐藏操作、遮罩拦截、pointer-events 或 order 改变可操作性。
- API 方法/路径/参数/正文/身份/请求次数变化，读操作触发新写入或计算。
- 图表丢失真实序列/缺口/精度，状态以假成功/旧数据兜底，比较差值越权展示。
- 原有测试失败、范围外文件变化，或同 fixture 回归不能解释的行为差异。

阻断时先记录差异与原因，暂停该模块，不自行修业务或放宽断言。若是既有缺陷，单列，不把修复冒充视觉调整。

## 5. 补充的次级页面视觉规格

- 登录/改密：浅色背景、居中白色表单卡、统一蓝色主按钮、原错误/提交态与焦点；强制改密不补取消。
- 用户菜单：真实用户名不缩成不可辨识图标；菜单层级不能被新侧栏/卡片遮住，保留原事件。
- K线弹窗/题材抽屉：统一边框、标题、间距、按钮；内容内部滚动，关闭始终可达，原遮罩事件不变。
- Walk-forward：按原字段分区的只读证据卡，长 ID/hash 可换行/查看，不新增编辑、刷新或重算按钮。
- 智能研究证据、报告归档/合同：统一面板但核验层级独立；无合同/不可核验使用真实提示，不采用原型成功徽章。
- PAPER 五弹窗：统一表单层级，全部风险/备注/确认文本可读；移动端一列，不把审批确认或关闭风险藏在折叠区。
