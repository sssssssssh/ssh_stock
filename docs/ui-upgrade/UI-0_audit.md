- 行业图仍取现有前 10、既有顺序与坐标范围；热门行业列表仍取前 15。不得新增原型示意行情折线或统计项。
- 热门题材 11 列：排名、题材、Heat、阶段、3日变化、排名变化、涨跌、净流入、涨停/连板、Breadth20、RPS60；保持行点击打开题材详情。

服务源码及其类型不属于视觉修改白名单。冻结的请求参数正文见 JSON `api_calls`，包括动态查询、method、body 和 AbortSignal；动态 PAPER 操作路径还以组件脚本指纹和逐控件 @click 表达式补足，不能把调用点表误当作完整唯一端点集合。

| 边界 | 原调用组 / 必保语义 |
| --- | --- |
| 基础请求 / 认证 | `/api/v1` 默认基址、credentials include、code/envelope、401/403；auth/me/login/change-password/logout |
| 总览 / 数据 | system/status/runtime/data-coverage/data-calendar、dashboard、stocks/pools、themes/overview、opportunities、sectors、research/signals/stats、jobs 查询与现有 sync-basic/backfill/recalculate 提交 |
| ResearchLab | research/status、themes stats/buckets/topn/lifecycle、left thresholds、right transitions、trends topn、opportunities buckets、positions、context、evaluate；日期和 research_type/horizon 使用现有规则 |
| 回测 | portfolio/backtests、analytics summary/series/compare、performance period/calculate/trade/episodes；保持当前 identity/hash 查询、完整 series 分页与原 Decimal 字符串 |
| 智能研究 | agent/status/chats/messages/turns/turn-archives；会话创建/软归档、幂等请求和恢复；walk-forwards study/validation/window 只读 |
| 报告 / 证据 / 合同 | agent/reports、archive、evidence、verify、contracts、verify-contracts、report-comparisons 及二者 export；复核是既有操作，不触发原算法计算 |
| PAPER | paper/status/accounts/performance/jobs、decisions/observations/proposals、账户子集合；create/activate/pause/close、observe/propose/approve/reject、advance/review-day/cancel 路径和正文不变 |

禁止改 services、types、utils 的语义、API、后端、migration、策略/阈值、PIT、版本/hash/owner/generation、账本或计算。仓库中无当前 UI 入口的 API 函数也不得借本轮添加入口。

图表保护：市场/行业图保持原数据与排序；回测图保持序列/刻度含义/标记/精度；K 线保持真实行情与均线计算；报告只显示安全冻结图与原始事实表；PAPER 图保持断点不连接、不平滑、SVG、安全 tooltip、2000 点门限、原始冻结值与错误降级。首批仅 CSS 外观，不开放图表脚本修改。
