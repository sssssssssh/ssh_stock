## 3. 浏览器一对一对照方法

新增 `scripts/ui_visual_browser.cjs`：同一真实 `App.vue`，同一合成用户/数据/权限/时间，先注入冻结 CSS，再使用新 CSS。其余生产源码由上述门禁保证一致。Vite 仅绑定回环地址，测试基址固定 `/api/v1`，API 全由本地测试拦截；未调用真实账户、生产 API 或业务数据库。

每个检查点对照：可见控件的文本、输入值、勾选/禁用、required/pattern/min/max、title/aria；原表头与单元格；该操作产生的请求方法/URL/查询/body 及次数。只规范化随机 request_id，并对同一步的并发请求按集合比较，不掩盖端点、参数或正文差异。新布局另检查整页无水平溢出，密集表仍可内部滚动。

场景包括：

- 八主导航、总览/题材详情、五 Research Tab、评估周期、数据三折叠、日历/页大小/翻页和三类任务提交。
- 用户菜单、自愿改密/取消、登录提交、强制改密；错误/空数据。
- 长短线、趋势池、K线 90/180/365；回测年度、Run 选择边界与三个排序。
- 智能研究未启用、上下文输入与移除、报告详情/合同；既有复杂恢复和比较授权继续由原组件测试及浏览器脚本覆盖。
- PAPER 四页签、九种账本集合及复盘、五类弹窗、人工确认勾选；功能关闭、schema 未就绪、ACTIVE/PAUSED/CLOSED 条件。

截图、前后 JSON 与运行汇总默认在 `frontend/coverage/ui-visual/`，可用 `BROWSER_ARTIFACT_DIR` 输出到仓库外；不提交测试生成物或合成截图。
