# V1.3 范围差集评估

W04 结论：DEFERRED，保留原 scope filters、旧键/current/stale 集合和删除掩码实现。
不引入临时 staging、数据库反连接替换或新生命周期，避免扩大本轮查询/暂存修复范围。

隔离 PG17、已有 500,000 条候选、public A 非空的测量：

- existing_keys 500,000、current_keys 1,000、stale_keys 499,000。
- 原范围键读取 12.720 秒，Python 集合差集 0.118 秒。
- 峰值 RSS 从 205,303,808 增至 392,265,728 字节。
- 仅抽样 500 条删除掩码真实写入私有候选，2 条 SQL、0.455 秒；最终回滚。

这是一次样本，不称为 p95，也不推断全量删除掩码吞吐或批准生产内存预算。
大范围键读取确实有内存成本，但本轮已定位的反复候选核对更优先；没有前后对照证明
