# V1.4 阶段 A 试运行边界

当前结论：READ_PERFORMANCE_OPEN，默认 `AB_MERGE_READ_ENABLED=false`。
本轮没有连接云端业务库、启停业务进程或重跑业务任务；提交代码不代表批准部署。
没有新迁移，迁移头保持 0058。历史预热输出范围没有缩短，历史复用尚未实现。

## 进入试运行的前提

先完成阶段 A 性能审阅和同 SHA 的全部 CI。当前百万级预实验新路径更慢，
不满足进入生产试运行的前提，不应直接打开开关。
需补测接近任务书行宽/约 6GB 候选的样本、冷暖缓存、读者负载、Windows/跨网，
保留实际游标全 FETCH 与锁/来源核验开销；不能仅凭 EXPLAIN 或首批返回宣称通过。
固定规划器参数只允许隔离实验解释，不得推广为全局生产配置。

条件满足后，仍需用户另行授权业务库只读核对、备份及恢复验证、部署和试运行。
先核对部署 SHA、PG17/0058、实际配置身份、现有任务与执行槽；确认旧 Writer/Scheduler
已按批准步骤停止。执行 token、凭据和私有连接信息不进入仓库或公开收据。
遇 RUNNING/未知提交，不得重放、释放槽、手改终态或用新 root 覆盖旧 root。

## 有限试运行

经批准后仅选 2～5 个真实开市日，不以春节休市区间作为性能样本，不直接下发全年任务。
完整日历缺失报 TRADE_CALENDAR_UNVERIFIED，无开市日报 NO_TRADING_DAYS；
均不通过补零行情或伪造日历绕过。开市日可入队不代表 Raw 质量已经合格。
监测 Worker 所有权、首批/每 FETCH、窗口耗时、PG 等待、RSS、质量、最终
SUCCESS/PUBLISHED 和公开来源一致性。成功后才另评审一个月规模。
57014/断线/WAIT 保存脱敏证据，遵守原有取消和未知提交处置流程，不自动重试。

## 回退与后续

安全等待当前 root 完成或按原协议取消并核对终态后，再将开关关闭用于后续任务；
不得在运行中的 root 中途改变配置、连接、版本或来源身份。不降级迁移，不重写 ledger、
预镜像、质量和公开 A，不用删除候选表规避锁/错误。开关只切换交易状态输入读取，
不是历史复用或新公式开关。
阶段 B 必须在阶段 A 验收后获得用户明确确认，先调查 Raw 修订/来源证据并审阅 ADR；
缺证必须保守处理。阶段 C 原生临时缓存未落地，也不因本报告获得授权。
